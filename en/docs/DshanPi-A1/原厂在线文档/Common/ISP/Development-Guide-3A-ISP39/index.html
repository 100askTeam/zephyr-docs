1 概述​

该⽂档主要介绍3A库的实现⽅式，旨在指导⽤⼾如何实现定制化的3A算法库。

3A算法库依赖于AIQ，AIQ内已包含有RK的3A算法库，并且已经默认使能。⽤⼾可根据需要按该⽂档⽅式实现定制化的3A库。

1.1 设计思路​

基本设计思路如下图所⽰：

3A库通过注册⽅式注册给ISP库，注意RK的3A库已隐式的注册，不需要⽤⼾显⽰注册

3A库注册给ISP库后，ISP库从驱动拿到3A统计后，回调3A库接⼝得到新的3A参数，ISP库将新的3A参数设置给驱动

1.2 ⽂件组织​

⽂件组织如下图所⽰：

ISP Firmware 分成应⽤层的librkaiq.so 和 驱动层 的 ISP 驱动以及外设驱动，包括 Sensor、VCM及Flashlight等

框架⽀持所有模块的算法库都使⽤客⼾算法，但⼀般来说，除3A库希望定制化外，其他基础库可使⽤RK提供的默认库。

1.3 开发模式​

⽀持以下三种开发模式：

3A库使⽤RK库。使⽤该⽅式时，RK的3A库API都可使⽤，具体包括：rk_aiq_user_api2_ae.h，rk_aiq_user_api2_af.h，rk_aiq_user_api2_awb.h。

3A库部分使⽤RK库，部分使⽤⽤⼾⾃定义库。如 AE 库使⽤⾃定义库，AWB 库使⽤RK库。

1.4.2 内部运⾏流程​

AIQ 内部运⾏如下图所⽰：

获取统计线程。该线程不断从ISP驱动获取 3A 统计，然后发送给 3A 计算线程。

3A计算线程。该线程收到统计后，开始调⽤各模块算法（包括第三⽅算法回调），计算新的参数，然后将新参数发给 ISP参数设置线程和 SOF线程。

ISP参数设置线程。该线程收到新的ISP参数设置请求后，在合适时机下发给ISP驱动。

SOF线程。该线程为 Sensor 帧头事件的响应函数，该线程收到新的曝光设置请求后，从队列中取出新曝光参数设置给Sensor驱动。

2.3 开发⽤⼾AF算法​

⽤⼾不使⽤RK AF算法库时，可以根据3A统计值开发AF算法，实现变倍对焦等功能。

⽤⼾实现AF算法时，

  1. ⾸先调⽤rk_aiq_user_api2_af_SetAttrib进⾏AF统计相关的配置；

  2. 其次使⽤rk_aiq_uapi2_sysctl_getIspStats获取3A统计值；

2.3.1 AF统计模块​

AF模块可选择 ch0Wb0Out/ch1Wb0Out/debayerIn/bayTnrOut/ynrOut/vicapOut的图像数据，作为AF统计的输⼊数据。

AF3.3⽀持主窗⼝A，它包含15*15⼦窗⼝，可以进⾏V1/H1/V2/H2四个滤波器的配置，输出V1/H1/V2/H2四个FV值、亮度值和⾼亮统计。

值。独⽴窗⼝B共享主窗⼝A的V1/H1/V2/H2滤波器的配置，输出V1/H1/V2/H2四个FV值、亮度值和⾼亮统计。

2.3.2 AF统计窗⼝配置​

主窗⼝A⽀持矩形窗⼝配置。可配置矩形窗⼝左上⻆坐标和窗⼝宽⾼。

2.3.3 Gamma​

Gamma将sensor输⼊raw图转换为⼈眼对⾃然亮度感知的程度，⽤于改善暗区对⽐度。x坐标分段为0 to 1023:

16 16 16 16 32 32 32 32 64 64 64 128 128 128 128 128

y坐标取值范围为0 to 1023。

2.3.4 Gaus​

可进⾏前置去噪处理，⼀般按如下配置即可。

0640
0640
000

2.3.5 DownScale​

DownScale对输⼊的AF统计信号进⾏下采样处理，有助于⽀持更低频的滤波器频带。

2.3.6 Focus Filter​

主窗⼝A提供V1/H1/V2/H2四个滤波器进⾏设置。

V1/H1/V2/H2四个滤波器的频带可以调整，使⽤滤波器设计⼯具，⽣成滤波器寄存器值。

常⻅的典型频带配置可采⽤[0.04n ~ 0.1n]，n为缩放⽐例，例如[0.01 ~ 0.025]、[0.02 ~ 0.05]、[0.04 ~0.1]、[0.08 ~ 0.2]等。

2.3.7 Luma/Highlight​

主窗⼝A提供亮度统计和⾼亮计数统计。

FV值容易受到光源的影响，在聚焦模糊的时候因为光晕扩散，图像中低频分量会增加，会出现图像模糊反⽽FV值变⼤的现象。

⼀般的解决⽅法是使⽤⾼亮计数器，聚焦模糊的时候因为光晕扩⼤，⾼亮点的个数会增加，清晰的时候，⾼亮点的个数会最⼩。

2.3.8 Luma Depend Gain​

光源的影响也可以通过 LDG功能进⾏去除，根据像素亮度对FV值进⾏衰减，降低过亮点和过暗点处FV值。

亮度值在[lumaL_thred, lumaR_thred]之间时，gain值输出为1，FV值不进⾏衰减；

亮度值在[0, lumaL_thred]之间时，gain值按照斜率slopeL_val进⾏衰减，gain值最⼩为gainL_val；

$$

\begin{array} { r l } & { \mathsf { g a i n } = 2 5 6 - { \mathsf { s l o p e L } } _ { - } { \mathsf { v a l } } ^ { \star } ( { \mathsf { I u m a L } } _ { - } { \mathsf { t h r e d } } - { \mathsf { x } } ) / 2 5 6 ; } \\ & { \mathsf { g a i n } = \mathsf { m a x } ( \mathsf { g a i n } , \mathsf { g a i n L } _ { - } \mathsf { v a l } ) ; } \end{array}

$$

亮度值在[lumaR_thred, 255]之间时，gain值按照斜率slopeR_val进⾏衰减，gain值最⼩为gainR_val；

⽔平⽅向H1/H2共享⼀条LDG曲线，垂直⽅向V1/V2共享⼀条LDG曲线。

2.3.9 Fv Coring​

当Fv值⼩于Fv thresh阈值信息时，输出Fv clip为0，不计⼊最后的输出。

当Fv值⼤于Fv thresh阈值信息时，输出Fv会乘上fv slope进⾏输出。

当Fv值⼤于Fv thresh阈值信息时，且输出Fv乘上fv slope之后⼤于fv limit时，会将输出fv限制为fvlimit。

Fv Coring是对滤波结果之后的LDG输出值做的阈值。

2.3.10 Fv Calc​

Fv值⽀持绝对值模式和平⽅模式，平⽅模式将Fv值做平⽅运算，可增⼤清晰位置的FV值的⽐重。

Fv值累计计算时可选择统计块内每⾏Fv的最⼤值模式和每⾏Fv的累加模式。

硬件滤波器单像素的输出位宽为10bit，累积寄存器位宽31bit。

为了避免窗⼝统计累加时溢出，需要根据统计模式和窗⼝尺⼨配置合适的shift移位寄存器，将像素FV值右移后再进⾏窗⼝累加。

⽬前主窗⼝⽤于shift的寄存器为3位，最多⽀持sum_shift=7，绝对值模式下⽀持的最⼤⼦窗⼝为2^(31+7-10)=2^28，平⽅模式下FV值不超过

20bit，⽀持的最⼤⼦窗⼝为2^(31+7-20)=2^18 (实际上，典型的带通配置下得到的FV值多数达不到上述⻔限，可以⽀持更⼤的⼦窗⼝)。

独⽴窗⼝⽤于shift的寄存器为4位，最多⽀持sum_shift=15，绝对值模式下⽀持的最⼤⼦窗⼝为2^(31+15-10)=2^36，平⽅模式下FV值不超过

20bit，⽀持的最⼤⼦窗⼝为2^(31+15-20)=2^26 (实际上，典型的带通配置下得到的FV值多数达不到上述⻔限，可以⽀持更⼤的⼦窗⼝)。

2.3.11 Fv Output​

主窗⼝A的输出包含15 * 15的v1/h1/v2/h2 Fv信息和15 * 15的luma/ highlight信息。

独⽴窗⼝B的输出包含1 * 1的v1/h1/v2/h2 Fv信息和1 * 1的luma/ highlight信息。

2.3.12 最终FV值的计算​

⽔平滤波输出H和垂直滤波输出V，可以⽤⼀定的权重进⾏加权。

FV = FvH * weight + FvV * (1-weight)

从各个block得到的FV值也可以根据需要按照⼀定的权重进⾏加权。
