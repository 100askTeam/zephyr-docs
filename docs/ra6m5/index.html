你会掌握的四项能力

01组织 Zephyr 应用

理解工作区与应用目录，通过 CMake 加入源码，用 Kconfig 选择软件功能。

02配置并使用设备

从设备树找到设备实例，启用驱动，通过统一 API 完成设备访问。

03编写 Zephyr 驱动

连接 Binding、设备注册、初始化与事件上报，将自定义驱动接入工程。

04构建、调试与验证

核对生成的配置与设备树，结合断点、串口日志和实物现象检查程序。
