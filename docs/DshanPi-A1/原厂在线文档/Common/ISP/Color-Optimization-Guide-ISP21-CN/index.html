2.1 功能描述​

自动白平衡算法能自动的计算WB gain (R G B通道的白平衡增益)，并将其与RGB通道分别相乘后，使受环境光影响的白色还原成纯白色，保证在各个光线条件下，相机成像色彩跟物体真实的色彩保持一致。当场景存在白点时基于自动检测的白点计算WB gain，当场景不存在白点时通过单纯色方法得到WBgain。色适应模块，对白平衡校正的目标进行调节，使白平衡校正后的图像尽可能与人眼感知的外貌一致。色调调整模块，根据喜好调整整体色调。由硬件的统计和软件的策略构成自动白平衡，如AWB流程图所示

3.1 功能描述​

由于Sensor频谱分布函数很难和视觉响应函数完全匹配，因此，可通过一个色彩校正矩阵(ColorCorrection Matrix,CCM)校正光谱响应的交叉效应和响应强度，使前端捕获的图像与人眼视觉保持色彩一致。

CCM标定工具支持对24色卡进行3x3 CCM（aij）的预校正。

$$

\left[ \begin{array} { l } { R _ { c c } } \ { G _ { c c } } \ { B _ { c c } } \end{array} \right] = \left[ \begin{array} { l l l } { \alpha _ { 1 1 } } & { \alpha _ { 1 2 } } & { \alpha _ { 1 3 } } \ { \alpha _ { 2 1 } } & { \mathbf { a } _ { 2 2 } } & { \mathbf { a } _ { 2 3 } } \ { \alpha _ { 3 1 } } & { \mathbf { a } _ { 3 2 } } & { \mathbf { a } _ { 3 3 } } \end{array} \right] \cdot \left[ \begin{array} { l } { R _ { c c a n e r a } } \ { G _ { c o n e r a } } \ { B _ { c o n e r a } } \end{array} \right]

调整CCM说明​

对比当前RGB和目标RGB值，手动调整CCM，使两者RGB接近。

（1）CCM调节约束​

颜色校正矩阵的公式如下：

$$

{ \left[ \begin{array} { l } { { \bar { R } } ^ { t } } \\ { G ^ { t } } \\ { B ^ { t } } \end{array} \right] } = { \left[ \begin{array} { l l l } { \alpha _ { 1 1 } } & { \alpha _ { 1 2 } } & { \alpha _ { 1 3 } } \\ { \alpha _ { 2 1 } } & { \alpha _ { 2 2 } } & { \alpha _ { 2 3 } } \\ { \alpha _ { 3 1 } } & { \alpha _ { 3 2 } } & { \alpha _ { 3 3 } } \end{array} \right] } { \left[ \begin{array} { l } { { \bar { R } } } \\ { { \bar { G } } } \\ { { \bar { B } } } \end{array} \right] }

$$

为了保证白平衡不受破坏，参数必须满足条件：

$$

a _ { i 1 } + a _ { i 2 } + a _ { i 3 } = 1

$$

各通道主要来源于原通道的颜色分量，因此必须满足条件：

$$

a _ { i i } \geq 1

$$

同时，尽量使主对角线元素值差异较小，尽量使主对角线以外的元素均为负值。

如果 $\alpha _ { 1 3 }$ 为正数，会导致高饱和度红色偏紫，如果 $\alpha _ { 3 1 }$ 为正数，会导致高饱和度蓝色偏紫。

当 $\alpha _ { 2 1 }$ 为负值时，绝对值越大，校正后的红色的G分量值越小，红色的饱和度越高； $\alpha _ { 2 3 }$ 为负值时，绝对值越大，校正后的蓝色的G分量值越小，蓝色的饱和度越高。

（2）常见色偏精调总结：​

蓝色（红色）偏紫， $\begin{array} { r l } { \alpha _ { 1 3 } } & { { } \left( \alpha _ { 3 1 } \right) } \end{array}$ 为正数时，需减小R（B）分量，将 $\alpha _ { 1 3 } \mathrm { ~ ~ { ~ \alpha ~ } ~ } ( \alpha _ { 3 1 } )$ 从接近0 的正数改为较小负数；

蓝色（红色）过饱和， $\begin{array} { r l } { \alpha _ { 2 3 } } & { { } ( \alpha _ { 2 1 } ) } \end{array}$ 为负值时，需增大G分量，可减小 $\begin{array} { r l } { \mathcal { A } _ { 2 3 } } & { { } \left( \boldsymbol { a } _ { 2 1 } \right) } \end{array}$ ）的绝对值；

紫色偏蓝，需增大R分量，可增大 $\alpha _ { 1 3 }$ ，减小 $\alpha _ { 1 1 }$ 和 $\alpha _ { 1 2 }$ ；或者减小B分量，减小 $\cdot a _ { 3 3 }$ ，增大 $\alpha _ { 3 1 }$ 和 $\alpha _ { 3 2 }$ ；

红色偏橘，需减小G分量，可减小 ${ \bf \nabla } \cdot { \bf { { a } } } _ { 2 1 }$ 并增大 $\boldsymbol { \alpha } _ { 2 2 }$ ；

肤色偏黄绿，需减小G分量，增大B分量，可大幅度减小 $\cdot \alpha _ { 2 2 }$ 和增大 $\alpha _ { 2 3 }$ ，微调 $\alpha _ { 2 1 }$ ，大幅度增大 $\alpha _ { 3 1 }$ 和减小 $\boldsymbol { \cdot } \boldsymbol { \mathcal { a } } _ { 3 2 }$ ，微调 $a _ { 3 3 }$

调整CCM示例

(1) 案例1 红色偏橘：

使用faststone 调整RGB 发现，减小G分量可以改善偏橘的问题，此时红色塑料片目标RGB值为[212 6379]。

红色框内的红色塑料片偏橘，RGB = [212, 78, 80]，与目标值[212 63 79]相比，G分量偏大。如果经验比较丰富，可以跳过获取用faststone这一步，直接调整CCM减小G分量即可。

$$

\begin{array} { r } { ( \tilde { \mathcal { T } } ^ { \prime } = \alpha _ { 2 1 } \bar { \mathcal { R } } + \alpha _ { 2 2 } \tilde { G } + \alpha _ { 2 3 } \bar { \mathcal { B } } \ , } \end{array}

$$

原校正系数： $[ a _ { 2 1 } , a _ { 2 2 } , a _ { 2 3 } ] = [ \phantom { - } 0 . 2 8 5 4 , 1 . 1 4 9 6 , 0 . 1 3 5 8 ]$

由于红色塑料片R分量值最大，因此需要减小 $\alpha _ { 2 1 }$ 的值，为了符合行相加为1的约束，需要减小 $\alpha _ { 2 2 }$ 的绝对值

调整后校正系数： $[ a _ { 2 1 } , a _ { 2 2 } , a _ { 2 3 } ] = [ - 0 . 3 8 5 , 1 . 2 4 9 7 , 0 . 1 3 5 8 ]$

红色塑料片： $\mathsf { R G B } = [ 2 0 8 , 5 6 , 7 6 ] _ { \bullet }$

(2) 案例2 肤色偏黄绿：

红色框内的肤色偏黄绿，RGB = [216, 174, 124]，其中G分量偏大，B分量偏小；

原校正系数： $\left[ \begin{array} { l } { a _ { 2 1 } , a _ { 2 2 } , a _ { 2 3 } } \ { a _ { 3 1 } , a _ { 3 2 } , a _ { 3 3 } } \end{array} \right] = \left[ \begin{array} { l l l } { - 0 . 3 1 9 2 } & { 1 . 6 9 2 7 } & { - 0 . 3 7 3 5 } \ { 0 . 0 2 3 9 } & { - 0 . 5 7 3 8 } & { 1 . 5 4 9 9 } \end{array} \right]$ 同案例1，减小G分量，大幅度减小 ${ { \cdot } } a _ { 2 2 }$ 和 $\alpha _ { 2 3 }$ 的绝对值，微调 $\alpha _ { 2 1 }$

此时相应位置的肤色：RGB = [212, 169, 124]；

为增大B分量，因为R和G分量值较大，因此大幅度增大 $\alpha _ { 3 1 }$ 和 $\alpha _ { 3 2 }$ 的绝对值，微调 $a _ { 3 3 }$

调整后校正系数： $\left[ \begin{array} { l } { a _ { 2 1 } , a _ { 2 2 } , a _ { 2 3 } } \ { a _ { 3 1 } , a _ { 3 2 } , a _ { 3 3 } } \end{array} \right] = \left[ \begin{array} { l l l } { - 0 . 3 0 0 4 } & { 1 . 6 3 7 5 } & { - 0 . 3 3 7 1 } \ { 0 . 2 1 2 7 } & { - 0 . 7 2 9 4 } & { 1 . 5 1 6 6 } \end{array} \right]$

此时相应位置的肤色： $\mathsf { R G B } = [ 2 1 4 , 1 6 9 , 1 4 6 ]$

4 高级颜色调整-3DLut​

4.1 CCM VS 3DLut​

CCM的任务是使不同光源下的颜色与人眼视觉相近，3DLut的任务是根据喜好去调整个别的颜色。两者对颜色调整的优缺点如下：

CCM3DLut
优点颜色过渡自然，不容易引人噪声对某个颜色的色调调整及饱和度调整比较容易；对不相近的颜色可以没有影响
缺点针对某个喜好，修改了CCM，可能会导致其他不相近颜色受到影响；颜色调整比较困难由于当前的采样点数9x9x9偏少，颜色容易过渡不自然，且调整了数值以后会影响像素点的去噪强度，会引入噪声

至于选择哪种方案，实际项目中在颜色喜好和过渡及噪声直接做权衡。
