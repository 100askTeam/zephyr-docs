# 认识实验套件

开始一期实验前，先确认 **DshanMCU-HPM6E70 实验套件** 底板上的 **13 路外设插座（`M1`–`M13`）** 与中央 **HPM6E70 核心板** 的位置、供电、信号引脚及共用引脚关系。

<KitExplorer mode="explorer" />

## 引脚复用与互斥插拔总表

由于底板将多种传感器集中引出至同一颗 HPM6E70 核心板，少数插座共用了相同的 MCU 引脚。在对应实验切换模块时，只需拔除冲突模块即可，无需拆装核心板：

| 本课使用插座 | 冲突插座 | 共用引脚 | 处理方式 |
| --- | --- | --- | --- |
| **M4** 红外发射 | **M9** 蜂鸣器 | `PF26 (PWM3_P_2)` | 做第 11 课（红外通信）前拔掉 M9；做第 2 课（蜂鸣器）前拔掉 M4 |
| **M2** DS18B20 | **M10** DHT11 | `PC06 (单总线)` | 做第 5 课（DS18B20）前拔掉 M10；做第 4 课（DHT11）前拔掉 M2 |
| **M6** HC-SR04 超声波 | **M12** W25Q64 Flash | `PB05` | 做第 6 课（超声波）前拔掉 M12；做第 12~14 课（Flash）前拔掉 M6 |
| **M1** OLED 双色屏 | **M11** MPU6050 | `PF12/PF13 (I2C1)` | **无冲突**（从机地址分别为 `0x3C` 与 `0x68`，可同时插在底板上使用） |

:::tip[关于右下内圈接口]
底板右下内圈另有预留电机驱动接口（未纳入一期 14 节实验），一期全部外设实验仅使用图中标出的 `M1`–`M13` 插座与中央核心板。
:::
