第 6 课：HC-SR04 超声波测距

在 HPM6E70 完整工程包中编译并烧录 applications/hc_sr04_demo，在底板 M6 插座上每秒触发一次 HC-SR04 超声波测距，并在串口打印精确到 0.01 cm 的距离读数。

M6 · HC-SR04 超声波测距模块

第 6 课 · Trig/Echo 高精度时间差换算厘米距离

⚠ 引脚复用提醒（需拔除冲突模块）
M6 的 Trig 引脚（PB05）与 M12（W25Q64 Flash）的片选 SPI5_CSn 复用！运行超声波测距前请先拔掉 M12 上的 Flash 模块。
核心引脚与信号映射
VCC (1)电源
Trig (2)PB05
Echo (3)PE01

本模块同时也是二期工程剖析课程的骨架外设，跑通第 6 课后可在二期深入学习它的自定义 Binding 与驱动实现。

编译与烧录命令 (hc_sr04_demo)
.\.venv\Scripts\python.exe -m west build -p always -b dshanmcu_hpm6e70 applications\hc_sr04_demo -d build\hc_sr04_demo
.\.venv\Scripts\python.exe -m west flash -d build\hc_sr04_demo
打开全套件交互导览图 →二期第 1 课：标准 Zephyr 驱动写法

将 HC-SR04 超声波模块插入模块化底板的 M6 插座：

模块引脚底板插座 M6核心板 J4HPM6E70 引脚说明
VCC1—3.3V / 电源模块供电
Trig24PB05触发信号（与 M12 SPI5 CS 复用）
Echo / INT35PE01回波脉宽信号（与 M12 INT 复用）
GND4—GND公共地
重要互斥：与 M12（W25Q64 Flash）互斥，注意模块电平
  1. 互斥引脚：M6（HC-SR04） 与 M12（W25Q64 SPI Flash） 共用 PB05 / PE01 引脚，两个模块不能同时插在底板上使用（第 12～14 课插 W25Q64 前需先拔掉本模块）。
  2. 电平提示：标准 HC-SR04 为 5V 器件，若自行外接不兼容 3.3V 的模块版本，需确认底板插座实际电路已做好分压/电平转换或使用宽压兼容版模块。

编译与烧录​

在 HPM6E70 工程根目录执行：

.\.venv\Scripts\python.exe -m west build -p always -b dshanmcu_hpm6e70 applications\hc_sr04_demo -d build\hc_sr04_demo
.\.venv\Scripts\python.exe -m west flash -d build\hc_sr04_demo

预期现象与串口日志​

烧录完成后打开串口终端（115200 8-N-1），并将探头正前方对准平整墙面或硬纸板移动测试：

  1. 核心板心跳灯：板载绿色 LED（PC22）每秒翻转一次；
  2. 测距输出：在探头正前方 5～150 cm 移动手掌或书本，串口每秒实时刷新一次厘米数；若正前方无有效反射面或超出量程/角度过大，会打印无回波提示；
  3. 串口日志示例：

常见问题排查​

现象排查方向
一直打印 distance: (no echo, target out of range)1. 确认 M12 插座为空（未插 W25Q64 抢占 PB05）；
2. 检查模块是否插紧在 M6；
3. 被测物距离太近（小于约 2～3 cm 盲区）、表面太软吸声或斜角太大导致声波未反射回探头，换硬质书本正对 30 cm 左右再试
读数偶尔跳变声波多次反射或多路径干扰属正常物理现象，保持探头与被测面大致垂直且避开杂物边缘
串口无任何输出确认 USB-HiSpeed-SERIAL-B 与 115200 8-N-1，烧录后按一次核心板 RESET 键
