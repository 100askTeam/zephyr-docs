软硬件与前置条件

实验硬件
DshanMCU-HPM6E70 开发板与模块底板包含 DshanMCU-HPM6E70 核心板、模块化扩展底板、CH347F 调试器（V12，提供 JTAG 与 USB-UART）及配套 M1–M13 外设模块。
开发主机
Windows 10 / 11 + PowerShell / VS Code教程所有构建与烧录命令均基于 PowerShell 验证，并同步兼容 VS Code 终端与常用串口助手（115200 8-N-1）。
前置基础
基础 C 语言阅读与命令行操作无需事先掌握 Zephyr RTOS，课程会沿着可验证现象逐层拆解设备树、Kconfig、驱动模型与板级配置。

工程包说明与目录分工

所有构建指令默认在工程根目录执行
一、二期完整工程包：解压即用，免装环境

工程包已内置 .west/ 清单、Zephyr 源码、sdk/（Python、west、Git、CMake、Ninja、RISC-V 工具链、OpenOCD）及 .venv/ 入口，无需激活虚拟环境或另行配置环境变量；仅在进入三期从空目录搭建时，按 三期环境准备 安装工具链。

HPM6E70/保存 Zephyr 内核、SDK Glue、Board 板级支持、一期/二期应用与驱动源码。构建与烧录命令默认在此根目录执行。
