HPM6E70 Zephyr 教程

从驱动开发到完整工程

一期以 HC-SR04 为主线，在现成工程中完成硬件描述、驱动、应用与真机测距； 二期从工作区开始，逐层接通 SoC、Board、Flash 与 SDRAM。

从开发准备开始已有完整工程，进入一期 →
Windows 10 / 11PowerShell 与 VS Code每一步真机验证

你会建立的四种能力​

01从硬件找到配置沿着原理图、引脚和控制器，把真实连接写进 Devicetree。
02完成 Zephyr 驱动理解 Binding、Kconfig、CMake、设备实例与驱动 API 怎样配合。
03让应用使用设备通过统一 API 获取设备、采集数据，并把结果变成可观察的日志。
04验证完整工程从构建产物追踪配置是否生效，再通过烧录、串口和实物现象验收。

从共同准备进入两条路线​

两期课程共用同一套开发环境、板卡认识、JTAG 和串口连接。先完成共同准备，再根据目标进入一期或二期。

00两期共用准备开发环境与硬件观察通道确认工程包、开发工具、HPM6E70 板卡、JTAG 驱动和串口日志。打开准备课程 →
01一期 · 先学会开发驱动、应用与设备树使用已经搭好的工程，以 HC-SR04 为主线完成一个外设从硬件描述到应用测距的全过程。进入一期课程 →02二期 · 再理解工程怎样组成从零搭建完整工程从 west 工作区开始，依次建立 SoC、Board、启动链、Flash 与 SDRAM 支持。进入二期课程 →

一期的开发流程​

一期不会要求你先搭建一块空白 Board。每一阶段只增加一个可验证结果，最后把它们组合成能够测距的应用。

01确认硬件信号TRIG、ECHO 与 GPIO
02描述设备节点overlay 与 Binding
03注册并实现驱动Kconfig、CMake 与驱动 API
04编写应用获取设备并读取距离
05构建和真机验证烧录、日志与测距结果

开始课程前​

硬件DshanMCU-HPM6E70 开发板、CH347F 调试器（V12）和 USB 线。
开发主机Windows 10/11。课程同时提供 PowerShell 命令和 VS Code 操作方式。
已有知识能够阅读基础 C 代码并执行命令；不要求提前接触过 Zephyr。
已经下载完整工程包

完整工程包已经包含课程需要的源码与开发环境，可以跳过软件安装，先完成板卡、JTAG 和串口检查，再进入一期。只有下载纯源码或工程中的 .venv、sdk_env 无法使用时，才需要重新搭建环境。

工程目录​

后续操作涉及两个彼此独立的目录：HPM6E70/ 保存 Zephyr 工程、板级支持和应用源码，zephyr-docs/ 保存教程网站。课程中的构建、烧录和调试命令默认从 HPM6E70/ 根目录执行。

依赖版本由工程中的 west manifest 固定。完成准备后，先从认识 Zephyr 与工程模型了解这些目录由谁使用，再进入一期或二期。
