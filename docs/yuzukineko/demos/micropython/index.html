MicroPython 脚本

在 YuzukiNeko 上直接运行交互式 MicroPython REPL，内置 machine、zephyr 与 F101 专属 f101 硬件模块（读取芯片 ID、调用 G2D 2D 加速器、音频输出）。单板接串口即可体验；插在底板带屏幕时，屏幕上还会同步显示复古黑底绿字控制台。

对应源码zephyr-components/micropython/micropython/ports/zephyr查看二期源码解析→

第一步：准备硬件与串口终端​

本体验使用接口供电与下载烧录（USB-C + FEL 按键） · microSD 扩展卡槽（SMHC0 · 4-bit SD）
板卡硬件概览 →
  1. 按 连接开发板与串口 接好 YuzukiNeko 与串口分线器（单板即可；若装在 YuzukiCube-M 底板并扣好 FPC1 排线，还能同时看到 1024×768 屏幕终端）。
  2. 在电脑准备好交互式串口终端软件（推荐使用 MobaXterm 或 PuTTY，参数设为 115200 8N1；不建议用仅按行发送的简易串口助手）。

第二步：下载并烧录固件​

11_micropython-full.img

2.54 MiB · SPI NOR 整片镜像 · LYNX Imager 主线模式直接写入

下载体验固件 11_micropython-full.img↓

下载完成后，打开 LYNX Imager（全志 F101 → SPI NOR → 勾选主线 · SPI NOR），按住开发板正面 FEL 键重新上电后导入该镜像写入并等待自动重启。完整图文向导见 烧录第一个体验固件。

第三步：在串口 REPL 中分步体验​

烧录重启后打开串口终端，敲一下回车键，看到 >>> 提示符即可逐段输入体验（接了底板屏幕时，屏幕同步滚动显示绿字）：

  1. 读取 F101 芯片 128 位唯一 ID 与查看剩余内存：
import f101, gc
f101.unique_id().hex()
gc.mem_free()
  1. 直接用 Python 控制 GPIO：
from machine import Pin
led = Pin(('gpiod', 5), Pin.OUT)
led.toggle()
  1. 体验开机软复位（约 1 秒后重启）：
import machine
machine.reset()

第四步：配置 TF 卡运行开机脚本 main.py（可选）​

如果想把脚本存到 TF 卡里让开发板通电自动跑，按下面步骤操作：

  1. 将 TF 卡格式化为 FAT32（注意这里用 FAT32），在根目录新建 main.py（确认无 .txt 后缀），写入示例脚本：
import time, f101
print("Hello from /sd/main.py! Chip ID:", f101.unique_id().hex())
for i in range(5):
    print("tick", i)
    time.sleep(1)
  1. 核对 TF 卡根目录结构并插入 YuzukiNeko 正面右侧卡槽：
TF 卡根目录/
└── main.py    # 开机由 _boot.py 挂载 /sd 后自动执行
  1. 重新上电即可在串口（与底板屏幕）看到自动执行输出，脚本结束后自动落回 >>> REPL，可用 import os; os.listdir('/sd') 查看卡内文件。

常见问题排查​

现象可能原因解决方法
打开串口一片空白启动横幅已输出完毕，正在等待输入敲一下回车或按 Ctrl + B 呼出 >>>；若无反应核对波特率为 115200 8N1
敲字不回显或无法执行误用了非交互式串口助手，或误按 Ctrl + S 暂停了流控改用 MobaXterm / PuTTY 并关闭软件流控（XON/XOFF）
无法挂载 /sd 或找不到 main.pyTF 卡未格式化为 FAT32 或文件名多了 .txt将 TF 卡重新格式化为 FAT32，确认根目录文件名严格为 main.py 后插卡重启
