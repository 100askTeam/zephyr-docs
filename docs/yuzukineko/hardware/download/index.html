硬件资料下载

所有硬件设计文件都托管在 GitHub：https://github.com/YuzukiHD/YuzukiNeko。点击文件名在 GitHub 上打开，再点下载按钮（或 Raw）即可。需要全部文件时，克隆仓库或使用 Code → Download ZIP。

git clone https://github.com/YuzukiHD/YuzukiNeko.git
提示

请使用与你手上板子同一版本的文件。版本差异见勘误与版本差异，目录结构见硬件文件说明。
