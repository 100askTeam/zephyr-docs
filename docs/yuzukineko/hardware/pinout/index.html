引脚排布

下表视角为元件面朝上，USB-C 接口在顶部，行号从 USB-C 一端向 microSD 一端递增。

警告

本文的“实际 SoC GPIO”列适用于所有版本。如果你用的是 V1.3，丝印从 PD10 起比真实 GPIO 小 2，务必先看勘误再配置引脚复用。

下表中 V1.3 丝印 是 V1.3 板子上印的名字；实际 GPIO / V1.4 丝印 才是 SoC 的真实引脚名，pinmux、软件和原理图都用这一列。加粗的是与 V1.3 丝印不同的项。

3V3、5V、GND 是电源脚，不是 GPIO。GPADC 是模拟输入脚，其通道、输入范围和基准电压请以原理图和 SoC 文档为准。

速查：按功能找引脚​

我要…可用引脚
普通 GPIO任何带 P 前缀的脚（Function0 输入，Function1 输出）
外部中断所有 GPIO 的 Function14（PD-EINTn / PE-EINTn / PB-EINTn）
模拟输入GPADC
控制台串口视软件而定，见板卡概览
显示输出PD0–PD9、PD12–PD22 及部分 PE 脚
红外接收PD5 / PD7 / PD22 / PE5 / PE6 / PB1 / PB3（IR-RX）

每个脚的全部复用功能见引脚复用 (MUX)。

注意​

  • 同一时刻一个脚只能选择一种功能；同一行里列出的功能互斥。
  • 显示、LVDS、MIPI DSI、USB 和 XIP Flash 属于高速或启动关键资源，接扩展硬件前请先核对你所用 BSP 的 pinctrl 设置、设备树和启动日志。
  • CAN 控制器只引出逻辑电平信号，接真实 CAN 总线需要外置收发器和正确的终端电阻。
  • 所有排针引脚均为 3.3 V 逻辑。
