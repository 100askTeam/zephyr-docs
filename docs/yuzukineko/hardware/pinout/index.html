下表视角为元件面朝上，USB-C 接口在顶部，行号从 USB-C 一端向 microSD 一端递增。

警告

本文的「实际 SoC GPIO」列适用于所有版本。如果使用的是 V1.3，丝印从 PD10 起比真实 GPIO 小 2，配置复用前请先核对 V1.3 PD 丝印勘误。

速查：按功能找引脚​

需求可用引脚
普通 GPIO任何带 P 前缀的脚（Function0 输入，Function1 输出）
外部中断所有 GPIO 的 Function14（PD-EINTn / PE-EINTn / PB-EINTn）
模拟输入GPADC
控制台串口配套工程统一为 UART1（PB0 TX / PB1 RX），见 板卡概览
显示输出PD0–PD9、PD12–PD22 及部分 PE 脚
红外接收PD5 / PD7 / PD22 / PE5 / PE6 / PB1 / PB3（IR-RX）

引脚复用 (MUX)​

下表中的「复用功能」是 SoC 在该引脚上可以选择的功能，同一时刻一个引脚只能选一种功能，在 Zephyr 设备树中通常通过 ALLWINNER_PINMUX(port, num, mux) 配置。

  • Function0 = 输入，Function1 = 输出；
  • Function11–13 保留；外部中断 EINT 是 Function14；
  • 表中使用的是实际 SoC GPIO 名。

常用外设引脚组合​

下表给出从排针中凑出的完整外设信号组合（括号内为 MUX 功能编号），选用前请核对是否与 YuzukiCube-M 底板占用引脚 冲突。

UART​

外设TXRXRTSCTS备注
UART0PE0（F6）PE1（F6）基本串口对
UART1PB0（F4）PB1（F4）PB2（F4）PB3（F4）默认控制台使用 PB0/PB1
UART2PD2（F4）PD3（F4）PD4（F4）PD5（F4）PE6 F3 / PE7 F3 备选（底板蓝牙 HCI 使用 PE6–PE9）
UART3PD0（F5）PD1（F5）PD3（F5）PD4（F5）PE8 F6 / PE9 F6 备选
UART4PD6（F5）PD7（F5）PD8（F5）PD9（F5）底板 CN2 引出 PD6/PD7；PE2–PE5 F6 备选
UART5PD17（F5）PD18（F5）PD19（F5）PD20（F5）避开编号较小的 PD 脚

I²C（TWI）​

外设SCKSDA备注
TWI0PE2（F4）PE3（F4）也可用 PD0 F6 SCK + PD2 F5 SDA
TWI1PD8（F3）PD9（F3）底板电容触摸使用 PD0 F4 / PD1 F4；PE0 F4 / PE1 F4 备选
TWI2PB2（F3）PB3（F3）PE4 F4 / PE5 F4 备选

SPI / I2S / CAN / PWM​

外设信号映射备注
SPI1PD0 CS0 / PD1 CLK / PD2 MOSI / PD3 MISO / PD4 HOLD / PD5 WP / PD6 CS1（均为 F3）可作 SPI 或 DBI；另有一组 PE 脚备选
I2S0PD6 MCLK / PD7 BCLK / PD8 LRCK / PD9 DOUT0（F4）+ PE4 DIN0（F5）装上 YuzukiCube-M 底板后与 Wi-Fi/UART4/DSI 冲突不可用
CAN0 / CAN1CAN0：PB2/PB3（F6，底板 U5 已接）或 PE0/PE1（F7）；CAN1：PE2/PE3（F7）或 PE8/PE9（F5）需外置收发器与终端电阻
PWM0CH0：PB0(F7)/PD1(F6)/PD6(F6)/PE2(F10)/PE8(F7)；CH1：PB1(F7)/PD7(F6)/PE3(F10)/PE9(F7)；CH2：PD22(F4，底板背光)/PB2(F7)/PD8(F6)/PE4(F10)/PE10(F7)；CH3：PB3(F7)/PD9(F6)/PE5(F10)每通道任选其一

注意事项与常见冲突​

  • 所有排针引脚均为 3.3 V 逻辑，同一时刻一个引脚只能选择一种复用功能。
  • 显示与 DBI/SPI1 共用 PD0–PD5，同一时刻只能二选一；在 YuzukiCube-M 底板上 PD0–PD3 已固定用于电容触摸。
  • I2S0 与 SDC2 共用 PE0–PE4，且 PE2 在裸板 USB 主机模式下用于 VBUS 开关；在 YuzukiCube-M 底板上 PE0–PE5 已用于 AIC8800 Wi-Fi SDIO。
