引脚复用 (MUX)

下表中的“复用功能”是 SoC 在该引脚上可以选择的功能，不是同时存在的功能，也不代表该功能在本板上已接线、已启用或有默认配置。每个引脚在 pinctrl/pinmux 软件中只能选一个功能。

通用规则​

  • 每个 GPIO 都可以当普通 GPIO：Function0 = 输入，Function1 = 输出。
  • Function11–13 保留；外部中断 EINT 是 Function14。
  • 表中 F<n> 即 pinmux 的 Function 编号，同一行里的功能互斥。
  • 在软件中通常用 port + 引脚号 + mux 三元组选择，例如 Zephyr 设备树里的 ALLWINNER_PINMUX(port, num, mux)。
  • 本文使用的是实际 SoC GPIO 名。V1.3 板的丝印请先按勘误换算。
