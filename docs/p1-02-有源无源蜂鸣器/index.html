第 2 课：有源/无源蜂鸣器

在 HPM6E70 完整工程包中编译并烧录 applications/buzzer_demo，驱动底板 M9 插座上的蜂鸣器循环播放 2000 Hz、2500 Hz、3000 Hz 测试音后静音 2 秒，同时分辨手头模块属于有源还是无源蜂鸣器。

M9 · 有源/无源蜂鸣器模块

第 2 课 · PWM 输出三段频率测试音

⚠ 引脚复用提醒（需拔除冲突模块）
M9 与 M4（红外发射）复用引脚 PF26 (PWM3_P_2)！做蜂鸣器实验前请先拔掉 M4 模块，以免红外 LED 随 PWM 同步高频闪发。
核心引脚与信号映射
VCC3.3V
GNDGND
OUT (I/O)PF26 (PWM3_P_2)

套件配套无源蜂鸣器可通过改变 PWM 频率输出不同音高；若误插有源蜂鸣器，只需固定高低电平即可长鸣。

编译与烧录命令 (buzzer_demo)
.\.venv\Scripts\python.exe -m west build -p always -b dshanmcu_hpm6e70 applications\buzzer_demo -d build\buzzer_demo
.\.venv\Scripts\python.exe -m west flash -d build\buzzer_demo
查看全板插座与复用总表 →

将配套的三针蜂鸣器模块插入模块化底板的 M9 插座（3.3V）：

模块引脚底板 M9 网络HPM6E70 引脚复用功能
VCC3.3V—3.3V 供电
GNDGND—公共地
OUTPA8（底板网络名）PF26PWM3_P_2（PWM3 通道 2）
重要互斥：运行前必须拔掉 M4 红外发射管

底板 M9（蜂鸣器） 与 M4（红外发射管） 共用同一根 PA8 / PF26 信号线。运行本示例前，务必先拔掉 M4 插座上的红外发射模块；三针模块注意核对 VCC / GND / OUT 方向，不要插反。此外，不要直接插只有两只引脚、没有驱动三极管的裸蜂鸣器。

编译与烧录​

在 HPM6E70 工程根目录执行：

.\.venv\Scripts\python.exe -m west build -p always -b dshanmcu_hpm6e70 applications\buzzer_demo -d build\buzzer_demo
.\.venv\Scripts\python.exe -m west flash -d build\buzzer_demo

预期现象与串口日志​

烧录后打开串口终端（115200 8-N-1，对应本机的 USB-HiSpeed-SERIAL-B COM 口）：

  1. 声音现象：模块会循环发出“低 → 中 → 高”三声短音（2000 Hz / 2500 Hz / 3000 Hz）并停顿 2 秒；
    • 无源蜂鸣器：能明显听出音调由低变高；
    • 有源蜂鸣器：内部自带振荡器，会以固定音色断续发声（两种情况均属正常，不会损坏模块）；
  2. 心跳灯：核心板绿色 LED（PC22）随每声提示与停顿周期翻转；
  3. 串口日志示例：

常见问题排查​

现象排查方向
串口日志正常，但完全没有声音1. 确认 M4 红外发射模块已拔掉；
2. 核对 M9 模块方向（VCC/GND/OUT 切勿反插）；
3. 确认使用的是带驱动电路的三针蜂鸣器模块，而非裸两脚蜂鸣器；
4. 若模块低电平触发，可将 applications/buzzer_demo/boards/dshanmcu_hpm6e70.overlay 中 PWM_POLARITY_NORMAL 改为 PWM_POLARITY_INVERTED 后加 -p always 重建测试
不发声期间也有微弱杂音或持续响模块为相反有效电平触发，按上条修改 PWM 极性后再测
串口无任何输出检查 USB-HiSpeed-SERIAL-B 端口与 115200 8-N-1 参数，烧录后按一次核心板 RESET 键
